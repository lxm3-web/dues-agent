# collect — 做本月催繳

1. 讀 `inbox/` 指示（若有）。
2. 用 Python 讀兩張表，依 `knowledge/02` 逐筆配對、算狀態、算級別。
3. 寫 `outbox/`（每檔最上面 `> 狀態：待確認`）：
   - `YYYY-MM_對帳結果.csv`：會員編號、公司、年費、入帳合計、狀態、依據、逾期天數、級別
   - `YYYY-MM_待人工確認.csv`：對不上的入帳（序號、匯款人、金額、最接近候選）
   - `YYYY-MM_催繳名單.csv`：要催的人，依優先順序，含聯絡偏好與建議動作
   - `YYYY-MM_收據清單.csv`：已繳的人（開收據用）
   - `YYYY-MM_催繳信/`：每人一封 `M0xx_公司.md`（未繳／短繳／重複各自範本）
   - `YYYY-MM_摘要.md`：統計＋三個發現＋下一步
4. `log/dues_log.md` 加一列。
5. 依 `knowledge/04` 三行交件。
