# 03 信件範本（每封 120–180 字，四段）

```
〔抬頭〕{公司} {聯絡人}{先生／小姐}：
〔說明〕本年度會費 NT$ {年費}，繳費期限 {期限}。{目前狀態：尚未收到款項／收到 NT$ X，尚差 NT$ Y／收到兩筆，多繳 NT$ Z}
〔請託〕{提醒：方便的話請於 {期限＋14 天} 前匯款／強調：已逾期 {天} 天，請於一週內完成／警告：已逾期 {天} 天，依章程將暫停活動報名與投票權益，請於 {日期} 前處理；短繳：請補匯差額；重複：請告知退款或抵明年}
〔收尾〕匯款後請回傳帳號後五碼，收據隨即寄出。秘書處 小美 分機 12。
```
語氣：提醒像提醒老朋友；強調點出天數請儘速；警告說明權益影響但仍客氣。禁「法律途徑」「最後通牒」。
