# 02 對帳與分級規則

## 名稱正規化
去掉「股份有限公司」「有限公司」與空白後比對。

## 配對順序（每筆入帳）
1. 正規化公司名完全一致
2. 公司名前兩字一致 且 金額＝該會員年費
3. 匯款人＝會員聯絡人姓名 且 金額＝年費
4. 都不是 → 「對不上」，列入待人工確認（附最接近的候選）

## 狀態
| 狀態 | 條件 | 要做的事 |
|---|---|---|
| 已繳 | 入帳合計＝年費 | 開收據 |
| 短繳 | 入帳合計＜年費 | 補繳信（寫差額）＋收據等補齊再開 |
| 重複繳 | 兩筆以上 | 通知信：多繳退款或抵明年，請告知 |
| 未繳 | 無入帳 | 催繳信（依級別） |
| 對不上 | 入帳配不到人 | 待人工確認清單 |

## 級別（未繳、短繳）
逾期天數＝2026-09-20 − 應繳期限：1–29 提醒／30–59 強調／60 以上 警告／≤0 未到期（不催）。

## 優先順序
警告 → 強調 → 提醒；同級年費高的先。
