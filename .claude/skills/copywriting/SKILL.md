# Copywriting（文案改寫）

## 標題公式

| 公式 | 例句方向 |
|---|---|
| 痛點＋解法 | 「分身乏術？教你策劃 AI 營運團隊」 |
| 具體數字 | 「4 小時，帶走 3 個能用的 AI Agent」 |
| 對話式提問 | 「派員工去學工具，真的有用嗎？」 |
| 反常識 | 「不用寫程式，也能自己建 AI 團隊」 |

避免抽象標題（例如「開啟你的 AI 之旅」）——讀者看不出跟自己的關係。

## 開頭三秒法則

第一句話要讓讀者判斷「這跟我有關」，不是鋪陳背景。網頁、EDM、社群貼文都適用。

**壞例子**：「隨著 AI 快速發展，企業經營者面臨前所未有的挑戰...」（讀者會直接滑走）
**好例子**：「派員工去學 AI 工具，回來還是沒人知道怎麼用——因為那張地圖只有你自己畫得出來。」

## FAB → BAF 改寫

傳統寫法 Feature-Advantage-Benefit（先講功能）常常讓讀者看不到跟自己的關係。改成 **BAF**：先講 Benefit（對讀者的好處），再講 After（用完之後的畫面），最後才帶 Feature（功能細節作佐證）。

| Before（FAB） | After（BAF） |
|---|---|
| 「本課程涵蓋個人特助、行銷經理、業務經理三個 Agent 建置」 | 「上完課，你會帶著一個能自己跑的行銷經理 Agent 回公司——課程內容涵蓋三個 Agent 的建置」 |

## 砍廢話檢查表

業務／行銷文案常見冗詞，改寫時逐一檢查：

- [ ] 「我們致力於」「我們秉持」→ 直接講做了什麼
- [ ] 「業界領先」「深受好評」「高品質」→ 換成具體數字或案例，沒有就刪
- [ ] 「隨著...快速發展」開頭 → 刪，直接進主題
- [ ] 一句話超過 40 字 → 拆成兩句
- [ ] 形容詞疊加（例如「頂尖專業的優質服務」）→ 留一個最有力的
